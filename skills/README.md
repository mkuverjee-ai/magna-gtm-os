# Skills

Claude loads these on demand. Company positioning and proof live in `company/context.md`; each campaign or segment is a play in `plays/<play-slug>/`. Outbound runs through Instantly (email) and Lemlist (email + LinkedIn), with AI Ark as the primary data source.

## Find the market

| Skill | What it's for |
|---|---|
| `gtm-philosophy` | Core GTM principles and how to coordinate channels. |
| `outreach-4-categories` | Sort leads into Inbound, Postbound, Bridgebound or Outbound and pick the approach. |
| `icp-matrix` | Build a 5-sheet ICP Matrix (accounts, prospects, personas, signal scoring, case studies) as .xlsx + CSVs. |
| `icp-tam-mapper` | Turn a domain or segment into an ICP Matrix plus a live AI Ark TAM/SAM/SOM breakdown. |
| `tam-scoring` | Build an 80-100 point scoring model and tier a company list T1-T4. |
| `pqs-builder` | Pain-qualified segments: membership test, measured count, sample rows, backtest, build spec. |
| `ocean-lookalike` | Clone a customer or seed domain into a list of similar companies. |
